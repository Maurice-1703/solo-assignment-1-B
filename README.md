# Vue 3 + TypeScript + Vite

## Setup

1. Repository klonen:
    git clone https://github.com/Maurice-1703/solo-assignment-1-B.git
    cd solo-assignment-1-B

2. Abhängigkeiten installieren:
    npm install

3. Entwicklungsserver starten:
    npm run dev

4. Im Browser öffnen (Konsole zeigt lokale URL an)
